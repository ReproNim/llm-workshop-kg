CNP KNOWLEDGE GRAPH AND COLLABORATIVE RESEARCH EXPERIMENT

Start with output/CNP_Knowledge_Graph_Experiment.html.
The slide deck is delivered separately. The factual graph is
experiment/results/combined_graph.ttl (1,113,959 triples).
The collaborative_example.ttl file is a SEPARATE ILLUSTRATIVE SCENARIO.
It does not attribute work to real people or claim an AbstractAtlas feature.

WHAT RAN
- All 52 phenotype TSVs and dictionaries at dataset commit 4070b6ee.
- NIDM/PROV graph construction, RDF parsing, SPARQL queries, local SHACL gates.
- One Barratt derivative recomputed for 272 participants; all match.
- StructSense 0.12.0 host-model structured subset, six authored records,
  unchanged upstream span validator, Ajv schema validation, source review.
- Four UMAP runs, PCA comparison, neighborhood/trustworthiness assessment.
- Illustrative person-role-question-input query and missing-reviewer mutation.

WHAT DID NOT RUN
- MRI content processing, per-participant imaging phenotypes, full historical
  lineage reconstruction, independent scientific replication.
- Full StructSense NER/resource pipeline or held-out skill benchmark.
- AbstractAtlas pipeline or integration into its deployed site.
- Blinded graph-versus-search LLM trial or long-horizon drift trial.

LAYOUT
experiment/data/phenotype: pinned public dataset tables and dictionaries.
experiment/results: graphs, coordinates, matrix, queries and validation results.
experiment/results/skill: frozen schema, extraction and review records.
experiment/vendor: pinned UMAP-JS bundle, Ajv bundle, StructSense subset/licenses.
research: participant and Git tree inputs required by deterministic rebuild.
output/cnp_graph: original graph components retained for integration.

The extraction outputs and claims_and_questions.ttl are frozen host-model
artifacts, not regenerated by these commands. skill_pilot.py records the
extraction assembly and test procedure; replaying its full original-offset
checks requires the original web-retrieval text snapshots, not included here.
Source URLs, hashes, exact short quotes and retrieval offsets are retained.
Re-fetching a page may yield different normalized text and offsets. Review
the scientific statement against the linked article, not just the short quote.

All raw phenotype values remain strings in RDF to preserve source values;
numeric conversion/imputation/scaling occur in the recorded embedding stage.
Session and acquisition containers are reconstructed; no historical timestamps
were inferred. Missing-value markers are explicit, and original TSVs retained.
The local SHACL profile checks required relationships; it is not a complete
NIDM certification or a scientific correctness certificate.
